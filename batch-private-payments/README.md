# Public 2 Private + Private 2 Private batch transacations

## 🚀 Quick Start

Ensure you have:

- [Node.js](https://nodejs.org) 12 or later installed
- [Yarn](https://yarnpkg.com) v1 or v2 installed

Then run the following:

### 1) Clone the repository

```bash
git clone git@github.com:AleoNet/batch-private-payments.git
cd batch-private-payments
```

### 2) Install dependencies

```bash
yarn
```

### 3) Development

Run a local server on localhost:3000.

```bash
yarn dev
```



### 4) Build

```bash
yarn build
```
